## Dil qaydası
- **8 dil CANLI:** `az` (default + I18nKey mənbəyi) · `en` `ru` `tr` `de` `hu` `it` `pl` (path-prefix routing `/en /ru /…`, `middleware.ts` PREFIXED). `az` tam həqiqət mənbəyidir, qalanları çatmayan açar üçün `az`-a düşür. Rus 8-ci dildir (`app/src/lib/locales/ru.ts` + `content-locales/ru.ts`).
- **Cəm (plural) qaydası:** say + isim **birləşdirilmir**. `tp(base, n)` (i18n.ts) formanı `new Intl.PluralRules(locale).select(n)` ilə seçir; lüğətlər yalnız formaları verir (`<base>.one|few|many|other`, `.other` MƏCBURİ fallback). az/tr yalnız `.other`, en/de/it one+other, ru/pl one/few/many/other. `Dict` genişləndirilib: `Partial<Record<I18nKey,string>> & PluralForms`, burada `PluralForms` = `app.plural.*` şablon-literal açarları. Səbəb: `I18nKey` **az lüğətindən** törəyir, azərbaycancada isə few/many forması yoxdur ki, açar törəsin — onsuz ru/pl öz qrammatikasının tələb etdiyi formaları elan EDƏ BİLMİR.
- **`X-Locale` header konvensiyası:** `app/src/lib/api.ts` **hər sorğuda** `X-Locale: getLocale()` göndərir (`t()`-nin render etdiyi eyni dəyər). Backend prioriteti: `body.locale` → `X-Locale` → `bagban_locale` cookie → `az`. Səbəb: brauzer **iki** `bagban_locale` cookie saxlaya bilər (panel split-dən əvvəlki host-only + `.agradex.com`) — Next `cookies.get()` birincini, Starlette sonuncunu götürür, ona görə interfeys bir dildə, AI prozası başqa dildə çıxırdı. Hazırda header-i yalnız `routers/advice.py::_resolve_locale` oxuyur (advice GET/generate + chat POST); yeni endpoint özü oxumalıdır — global middleware YOXDUR.
- **Backend proza = CODE + PARAMS:** farmerə görünən mətn Python-da cümlə kimi qurulmur. Modul stabil `*_code` + xam `*_params` qaytarır, köhnə AZ cümlə **fallback** kimi qalır (dəyişiklikdən əvvəl yazılmış sətirlər üçün); frontend `tf()` ilə həll edir (`app/src/lib/wellnessText.ts`). Bir yol digərinin mətnini əvəz edirsə **kodu da əvəz etməlidir** (FAO-56 balansı 7-günlük tövsiyəni əvəz edəndə kodu `pop` etmək canlı bug idi).
- Bütün kod, identifikator, SQL, sxem, commit mesajları **İngilis dilində**.

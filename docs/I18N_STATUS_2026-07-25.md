## 2. QƏRAR VERMƏLİ OLDUĞUN MADDƏLƏR

### (A) #3 — app.agradex.com platforma bölünməsi  ⏸️ SƏNİN ADDIMIN LAZIMDIR
Kod + DNS + SSL tam hazırdır və **dormant** gözləyir. Aktivləşmə üçün `/opt/bagbanai/.env`-ə 2 sətir əlavə edib deploy lazımdır:
```
NEXT_PUBLIC_PANEL_HOST=app.agradex.com
COOKIE_DOMAIN=.agradex.com
```
sonra `cd /opt/bagbanai && bash deploy/update.sh`.
**Niyə mən etmədim:** (1) avtomatik rejimdə `.env` (canlı auth-a təsir edən) dəyişikliyini təhlükəsizlik klassifikatoru bloklayır; (2) `COOKIE_DOMAIN` dəyişikliyi **mövcud bütün istifadəçiləri bir dəfə yenidən login** etməyə məcbur edir — bunu sənin bilərəkdən etməyin daha doğrudur; (3) parolsuz authenticated axını tam test edə bilmirəm. Hazırda app.agradex.com işləyir (SSL etibarlı), sadəcə host-ayrımı və paylaşılan sessiya hələ aktiv deyil. Detal: `deploy/PANEL_ACTIVATION.md`.

### (B) Wave 3 son qalıq — lib DATA faylları  🔨 QALIB (kiçik, amma incə)
Bütün EKRANLAR və komponentlər tərcümə olundu (yuxarı). Qalan yalnız **lib data modulları**:
- `lib/metadataOptions.ts` (~115): məhsul/sort/torpaq dropdown seçimləri (label-lar) — CROP_OPTIONS, VARIETY_OPTIONS_BY_CROP, SOIL_TYPE_OPTIONS, PH_BANDS. `value`=enum (saxla), `label`=tərcümə (basemap kimi render-də `t()`).
- `lib/indexStatus.ts` (~39): INDEX_LABELS/INDEX_INFO (indeks→ad/təsvir) + `interpret()` funksiyası (az cümlə şablonu).
- `lib/insights.ts` (~35): `cropLabelOf()` + `buildInsights()` (az cümlə generasiyası).
- `lib/regions.ts`: AZ_RAYONS = rayon adları = XÜSUSİ İSİMLƏR → tərcümə OLUNMUR (yer adları hər dildə eyni qalır); COUNTRIES "Azərbaycan" (1 giriş).
Bunlar data + funksiya-içi cümlə şablonları olduğu üçün JSX süpürgəsindən fərqli, daha diqqətli iş tələb edir (ona görə axıra saxladım). Nəticə: dropdown label-ları + indeks adları + insight cümlələri hazırda az fallback edir (ekran chrome-u tam tərcümədir). Davam etmək istəsən eyni yolla (label→t(), funksiya-içi t()) həll olunur.

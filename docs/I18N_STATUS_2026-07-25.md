## 2. QƏRAR VERMƏLİ OLDUĞUN MADDƏLƏR

### (A) #3 — app.agradex.com platforma bölünməsi  ⏸️ SƏNİN ADDIMIN LAZIMDIR
Kod + DNS + SSL tam hazırdır və **dormant** gözləyir. Aktivləşmə üçün `/opt/bagbanai/.env`-ə 2 sətir əlavə edib deploy lazımdır:
```
NEXT_PUBLIC_PANEL_HOST=app.agradex.com
COOKIE_DOMAIN=.agradex.com
```
sonra `cd /opt/bagbanai && bash deploy/update.sh`.
**Niyə mən etmədim:** (1) avtomatik rejimdə `.env` (canlı auth-a təsir edən) dəyişikliyini təhlükəsizlik klassifikatoru bloklayır; (2) `COOKIE_DOMAIN` dəyişikliyi **mövcud bütün istifadəçiləri bir dəfə yenidən login** etməyə məcbur edir — bunu sənin bilərəkdən etməyin daha doğrudur; (3) parolsuz authenticated axını tam test edə bilmirəm. Hazırda app.agradex.com işləyir (SSL etibarlı), sadəcə host-ayrımı və paylaşılan sessiya hələ aktiv deyil. Detal: `deploy/PANEL_ACTIVATION.md`.

### (B) Wave 3 — tətbiq daxili (app interior) tərcüməsi  🔨 QALIB (böyük)
Publik sayt bitdi; **login-dən sonrakı UI** hələ Azərbaycancadır (~90 fayl: `field/*`, `home/*`, `shell/*`, `app/inventory·sales·admin·...`, `lib/metadataOptions·regions·insights·indexStatus`). Bu, əsasən azərbaycandilli fermerlərin gördüyü hissədir — ona görə publik saytdan sonra prioritetləşdirdim. Eyni sınanmış pipeline ilə (extract → 6-dilli workflow → build gate → deploy) davam etmək olar; enum dəyərlərinə (məs. severity `aşağı/orta/yüksək`) diqqət lazımdır. **De ki davam edim, yoxsa bu sənin üçün lazım deyilsə buraxaq.**

### (C) Machine-translation keyfiyyəti  ⚠️
Tərcümələr **maşın** tərcüməsidir (yüksək keyfiyyətli, amma) — xüsusən aqronomiya terminləri (fındıq, gübrə, çiləmə, indekslər) hər dil üçün ana dili daşıyıcısı tərəfindən nəzərdən keçirilməlidir. az mənbədən əskik açar avtomatik az-a düşür (səhv göstərmir).

### (D) Browser-tab başlıqları (metadata)  minor
İndeks səhifələrinin bəzi `<title>`-ları (məs. /pricing → "Qiymətlər — Bağban AI") hələ az-dır (SEO/tab). Body tam tərcümədir. Düzəliş: `export const metadata` → `generateMetadata()` + getT (kiçik iş, təxirə saldım).

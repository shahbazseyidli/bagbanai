## 5. Tapılan real qüsurlar — sinif üzrə

### 5.1 Kadr dövrəsi qüsurları (bu layihənin təkrarlanan xəstəliyi)

Üç ayrı yerdə eyni kök səbəb: **gizli tab kadr istehsal etmir**, ona görə `requestAnimationFrame`
və `ResizeObserver` çağırışları **heç vaxt gəlmir**.

1. **MapLibre** — arxa-fon tabında qurulan xəritə style-ını yükləmir. Simptom: düzgün ölçülü canvas,
   işləyən kontrollar, **sıfır konsol xətası**. Həlli `lib/useMapReady.ts`.
2. **`useStageWidth`** — iş masası eni `ResizeObserver`-i gözləyirdi, gizli tabda **əbədi skeleton**
   göstərirdi. İndi `getBoundingClientRect` ilə **sinxron** ölçür (kadr tələb etmir).
3. Canlı sübut: gizli tabda 1066×460 ölçülmüş div-ə **yenicə bağlanmış** observer bir dəfə də
   işə düşmədi.

> **Qayda:** kadr dövrəsindən asılı hər hansı ölçmə mütləq sinxron fallback ilə yazılmalıdır.

### 5.2 «Funksiya var, amma əlçatmazdır»

- **Desktop iş masası** `WORKBENCH_MIN = 920` ilə göndərildi, real stage isə 1440px laptopda
  **778px**-dir. Ekran fiziki olaraq 1440 olduğu üçün **heç bir pəncərə ölçüsü onu aça bilmirdi.**
  760-a endirildi.
- **Push** `pywebpush` `requirements.txt`-ə əlavə edilmədən göndərilmişdi — lazy import qəsdən
  yumşaq deqradasiya üçündür, amma bu, VAPID açarları qoyulandan **sonra da** dormant qalması
  demək idi.

### 5.3 Dürüstlük qüsurları

- **Yanlış «kritik» hökm:** NDMI proxy-si xətti xəritə ilə 0-a çatırdı; 45/100 bitki örtüyü olan
  sahə **28/100 «su balansı kritik (0/100)»** olurdu — həm də bunu «(hesablanmayıb)» sətrinin
  **altında** yazırdı. Proxy indi 25–85 bandına sıxılır və **öz adını** daşıyır.
- **Kvota bitəndə 200 OK** — `{"quota_exceeded": true}` uğur kimi oxunurdu. İndi **429**.
- **Tur örtüyü** öz 2-ci addımının istədiyi toxunuşu udurdu (`pointer-events`).
- **Çat çipləri xəta halında açıq qalırdı** → free fermerə satış cümləsi qaytaran tıklama təklif edirdi.
- **`mark_read`** susdurulmuş bildirişləri istifadəçi görmədən oxunmuş damğalayırdı.

### 5.4 Dil qüsurları

- **Hər avtomatik AI məsləhəti azərbaycanca yaranırdı** — `/internal/advice/run` `lang` ötürmürdü.
  İndi org sahibinin dilini götürür (**0049** `advice.lang`).
- **İki `bagban_locale` cookie** (host-only + `.agradex.com`): Next birincini, Starlette sonuncunu
  oxuyur. İndi UI hər sorğuda **`X-Locale`** göndərir, backend onu üstün tutur.
- **Cəm formaları** — «1 полей», «1 fields». `tp()` + `Intl.PluralRules`; `Dict` genişləndirildi,
